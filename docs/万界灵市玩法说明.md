# 万界灵市

本模块采用现货股票与钱庄借款玩法，灵石买入整数股、卖出兑回灵石。主动借款可以扩大交易规模，也会留下需要还本付息的负债。期货式杠杆、做空和强平留待后续单独设计。新增入口为 `apps/User/LingshiMarket.js`，随 Yunzai 的递归插件加载器加载，重启机器人后生效。

## 行情与交易

- 北京时间 08:00—24:00 开市，每 10 分钟结算一次，全服共用行情。夜间允许查看、交谈、打听与查账。
- 八家商会初价均为 10000 灵石。丹鼎阁、天工坊每日限幅为昨收 ±5%；灵矿商会、万兽山、四海商盟、太虚符行为 ±10%；问天秘境、渡劫仙舟为 ±15%。
- 涨跌停限制普通报价，触及后可以反向波动，买卖继续按系统报价结算。商会退市时按股权清偿价值 0 清算，此终止事件不受每日跌停限制。这里采用系统流动性，没有玩家订单簿或封板排队。
- 成交额和余额使用安全整数；买卖手续费各为成交额 0.3%，向上取整。股数为 1—100000 的整数，单股累计持仓最多 100000 股，所有持仓的剩余成本合计最多 10 亿灵石。
- 同一玩家交易间隔 30 秒；标准消息标识用于最近 40 次成功操作的防重复回执。插件自身全服和玩家写入串行，适用于一个机器人进程；共享存档的多进程部署需另行引入分布式锁。
- 玩家交易与消息消费只写一次玩家文件；行情先保存再结算玩家，没有跨文件扣钱与发股的半笔交易。交易关闭每日任务的收入计数，避免卖股回款被当成额外日常产出。
- 停机后按保存的随机种子补算，每次最多 1008 个十分钟时段。补算期间暂停新交易与收费互动，重新查询会继续补算。存档损坏会报错停结算，不会重新生成行情覆盖旧档。

## 暴利、重亏与退市

重大利好和经营逆风持续 4—9 天，分别给每次报价施加向上或向下的倾向，并受每日涨跌停、NPC 买卖和随机波动共同影响。利好期间可以跨日连续涨停并翻倍，也可能被其他卖压抵消；没有固定胜率或保本收益。中途追高仍可能遇上利好落幕后的回撤。

经营危机持续 3—5 天，发生时公开发布“退市风险预警”和复核时间。复核前普通报价继续遵循每日限幅，玩家可以卖出离场；风险提示常驻行情图，危机期间的买入回执也会再次提示。复核成功则继续经营，失败则终止交易、股权清偿价值归零。低风险股票发生危机与清算失败的概率较低，但仍有损失全部投入的可能。

每天首个开市报价中，无持续事件的商会分别以低风险 6%、中风险 12%、高风险 20% 的概率进入新事件。事件中 50% 为重大利好、30% 为经营逆风、20% 为危机；危机复核失败概率分别为低风险 10%、中风险 25%、高风险 45%。这些是游戏参数，事件持续时不重复抽取新事件，各商会也并非每天独立完成一次抽签。结果不依据玩家仓位或余额临时指定。

退市清算只核销该股剩余持仓成本，自有灵石的现货买卖本身不会产生欠款。若已主动向钱庄借款，借据和利息会继续保留，股票归零也可能导致资不抵债。玩家离线期间同样承担风险，停机补算也不会绕过已发生的清算。榜单即时将归零股权计价为 0；玩家下次发送灵市指令时，将原持仓成本一次性转为已实现亏损并展示清算通知，重复查询不会重复扣账。

NPC 的同股仓位也归零、确认损失，之后不再交易该股。商会编号与退市记录保留，不自动重新上市，防止旧股权被新公司错误复活。未增加新商会补位或发行玩法。

固定种子仿真中，四个独立市场各推进 60 天，均出现过股价超过初价两倍与商会退市归零。样本最高价为初价约 21.90 倍；这只是可重现的玩法样本，不代表每个玩家、每只股票或每段时间都能获得相同结果。测试还核验了实际卖出确认翻倍利润、持仓损失 100%、NPC 同步承担损失及重复清算防护。

## 钱庄借款、负债与还款

四海钱庄提供系统授信，钱万三负责接洽与催债。借款与这位 NPC 自己的股票持仓资金分开记账，不改变 NPC 已有现金和历史成交，也不会读取未知玩家来决定行情。

- `#灵市借款 金额` 先展示完整借据与风险；`#灵市借款 金额 确认` 才会签约到账。普通下单余额不足时仍会失败，不会自动借钱。
- 金额须为整数，最低 10000 灵石；授信额度为借款当时随身灵石加持仓预估卖出净额的 2 倍，最高 5000 万。每人同时只持有一笔借据，旧本息还清后才能再借。
- 期限为借出时刻起 7×24 小时。日息为剩余本金的 0.1%，向上取整；借出时先计首日息，以后每满 24 小时再计下一日息。利息不再生利息，本笔累计计收利息封顶初始本金，即未还本息最多为初始本金两倍。
- `#灵市债务` 展示剩余本金、未付利息、本息总额、到期时间和净资产。净资产为随身灵石加持仓预估卖出净额，再减去欠款，可以为负数。背包的 `灵石` 字段保持非负，债务单独放在 `灵市.loan`，避免干扰其他修仙玩法。
- 离线同样计息。查询面板、榜单时按当前时间预估；下次灵市指令将新利息一次性写入账户。重复查询、重启和消息重放不会重复计收。
- 逾期或净资产小于 0 时暂停新买入；仍允许卖出现有股票、还款、查询、与 NPC 交谈，以及继续参加其他修仙玩法获得灵石。聊天或债务查询中会出现钱万三的催债提示。
- `#灵市还款 金额` 先偿还未付利息，再冲减本金。`#灵市还款 全部` 扣除“当前可用灵石”和“所欠本息”中较小的一项，资金不足时仍可先还一部分；不会将随身灵石扣为负数。
- 还款全天开放，行情正在补算时也可进行。清偿后借据注销、限制解除；资不抵债不自动免除本金，不自动变卖装备，也不引入永久封号、强制扣其他资源或破产清零。
- 利息按计提时计入灵市成本。借入本金不算收益，偿还本金也不重复算亏损；借据与灵石余额同一玩家文件一次写入，写盘失败后仍可重试。

例：自有 100 万灵石，借入 200 万，首日计息 2000。以每股 10000 买入 299 股，含手续费支出 2998970，随身剩 1030。若持仓在 3 天后全部归零，欠款为本金 200 万加 8000 利息，净资产为 -2006970；随后可用剩余 1030 先还部分利息。这里是“亏完自有本金后仍欠钱”的实际结算路径，股票上涨卖出时则可先还债、再保留剩余收益。

## NPC 的资产与行为

八位客商具有独立灵石、真实持股、持仓成本、手续费与已实现盈亏。起始资产由游戏设定发放；此后买入消耗灵石，卖出受现有份额限制，持仓随市价浮动。每个报价周期先执行 NPC 交易，再将净订单压力、公共市场波动和商会事件共同作用于下次报价。

| NPC | 习惯与互动 |
| --- | --- |
| 钱万三 | 估值派掌柜，喜欢日内相对低价，也会判断失误 |
| 白知微 | 了解丹药行情，对丹鼎阁更关注 |
| 陆听风 | 消息贩，转述真假不一的盘面判断 |
| 墨九 | 操盘客，经历吸筹、造势、分批出货、休整 |
| 沈红绫 | 追强势的游资，方向转弱会撤退 |
| 韩小满 | 易追涨、恐慌卖出的散修 |
| 宁不争 | 逆势接盘，可能接在下跌途中 |
| 燕归鸿 | 带来商路见闻，消息可能过时 |

墨九会在买入时公开造势，在出货时仍喊“洗盘”“拿稳筹码”。出货造成真实卖压，但随机行情与其他 NPC 的交易可能抵消卖压，操盘也会失败。剧情不读取玩家财富来定向改变价格；玩家持有其目标商会时，他会在私下交流中邀请护盘或加仓。玩家可从已发生的减持记录看出言行矛盾。

## 打听、查账与追问

- `#灵市交谈 NPC名` 免费，每个报价时段首次交谈增加 1 熟悉度，上限 100。重复交谈返回同一句，不刷好感。
- `#灵市打听 NPC名 [商会名/编号]` 花费 1000 灵石。省略商会时优先选择玩家与操盘客共同持有的商会，其次为玩家持仓、操盘客关注商会或丹鼎阁。
- 同一 NPC、同一报价时段的打听只收费一次，换商会也返回该时段原消息。查账同样每人每时段缓存一次，避免重复扣费。
- 消息根据当前趋势、人物立场与固定消息种子生成，不预读未来。熟悉度只略微改善普通消息的方向判断，操盘客的利益冲突仍然存在。付费不保证准确，也不保证推荐盈利。
- `#灵市查账 NPC名 [商会名/编号]` 花费 5000 灵石，展示最近四次相关成交、当下持仓、余额与已实现盈亏，不披露计划或下一次行情。
- `#灵市追问 NPC名` 在打听满 30 分钟后免费核验，采用发布后 30 分钟起的第一个开市报价作为固定参考。休市期间等待下次开盘；晚追问不改变结论。核验只评价方向，不代表扣费后有利润。
- 核验结果写入个人往来记录，兑现增加熟悉度，未兑现降低熟悉度。每条只核验一次。近期价格最多保存 160 个开市报价；超过保存期的消息结案但不计兑现率。

```text
#灵市 / #股市
#股票详情 丹鼎阁 / #股票走势 1
#买入 丹鼎阁 100
#卖出 丹鼎阁 50 / #卖出 1 全部
#我的股票
#灵市排行榜
#灵市收益榜
#灵市人物
#灵市交谈 墨九
#灵市打听 墨九 丹鼎阁
#灵市查账 墨九 丹鼎阁
#灵市追问 墨九
#灵市消息
#灵市帮助
#灵市借款 2000000
#灵市借款 2000000 确认
#灵市债务
#灵市还款 100000
#灵市还款 全部
```

净盈利榜按已实现盈亏、持仓预估卖出净浮盈、消息消费及已计借款利息合计排序；收益率的分母为累计买入含手续费金额与消息支出，收益榜要求累计投入至少 10 万灵石。借款本金不计利润，榜单另显示当前欠款。NPC 收益与玩家榜分开，防止初始设定资金污染玩家排名。

## 存档与验证

全服行情及 NPC 资产保存在插件目录的 `data/lingshi-market.json`，已加入 Git 忽略。个人持仓、交谈、消息、熟悉度、借据、累计利息成本与操作回执保存在玩家文件 `灵市` 字段。无借据的旧玩家按零欠款读取，首次成功互动时保存新增字段。

行情图、单股走势图与持仓图使用 `resources/html/lingshi_market/lingshi_market.html`；图片渲染失败时返回文字行情。

```sh
node --test test/lingshi-market.test.js
node --check apps/User/LingshiMarket.js

```
