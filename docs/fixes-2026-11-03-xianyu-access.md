# 仙域准入指引与仙古访客大宇宙修复

仙古至尊冲击真仙，需要仙域或法则足以承载目标境界的玩家大宇宙。原仙古入口读取大宇宙时只查本人编号，导致已经进入他人宇宙的访客仍被地点检查拦截。

本次调整：

- 仙古冲关优先使用当前 `大宇宙位置.界主` 查询所在宇宙；未处于访客状态时沿用本人宇宙的原规则。
- 实际访问宇宙不存在或法则不足时保持拒绝，不借用玩家自己另一座宇宙的法则。
- 仙域境界不足提示新增角色当前三体系等级；仙古至尊同时显示已有成仙通路。
- 至尊可使用 `#大宇宙列表` 查找开放宇宙，`#进入大宇宙 宇宙名`（或指定界主）进入后再 `#冲关`。初生宇宙可承载真仙；更高目标仍需对应法则。诸天位面、道途、资粮和渡劫条件照常检查，进入宇宙不代表自动突破。
- 也可沿原红尘仙路修行。九世完成后，需身在遮天、帝尊已败且成仙路开启，才可用 `#轰击成仙路` 入仙域；条件取各自服务器的世界状态。

普通仙域传送门槛、其他体系、穿梭费用、已成就境界、战斗数值、宇宙法则等级及开放规则保持。此修复针对公开插件版本，不迁移或修改玩家存档。

验证包含真实冲关入口派发、宿主与自有宇宙优先级、低法则拒绝、失效宿主、离开宇宙、关闭入口、原全局世界上限、旧自有宇宙和仙域位置，以及真实准入提示；不会在测试中执行生产突破。
