# 花粉分支回炉保留与旧档识别

回炉重造仍按原规则降低额外体系境界并清除极境成果。本次修复已进入大宇、究极或宇究后，回炉把分支身份一并清除的问题。

- 回炉后仍在宇究及以上境界时，保留宇究分支，已有大宇或究极的前身记录继续保留。
- 宇究退回大宇／究极境时，按明确记录恢复原分支。缺少前身记录的旧档保持待核对，不按后来补修的究极根基猜测历史。
- 降回分岔之前的境界时，清除当前分支并记录回炉前的分支依据。重新进化到大宇／究极境时按本次实际根基择路，旧历史不会替代新选择。
- 花粉状态、分支属性、悟道和极境选择采用同一分支识别。旧高境档恢复共同的宇究身份时，不补发极境或奖励；专属大宇／究极试炼仍需明确的原分支依据。

回炉降境、极境清除、进化成功率、失败惩罚、材料和费用沿用原规则。
