# 域外灾厄管理员召唤

机器人主人，或修仙配置 `Master` 列表中的管理员，可使用以下指令；配置中的账号支持数字或字符串。群主、群管理员身份本身不授予此项全服权限，管理员无需先创建修仙角色。

| 指令 | 效果 |
|---|---|
| `#召唤灾厄` | 立即召唤1尊普通域外灾厄 |
| `#召唤灾厄 5` | 立即召唤5尊；每次数量限1～10的整数 |
| `#召唤域外灾厄 3` | 同一功能的完整名称写法 |
| `#域外灾厄` | 查看当前灾厄列表与最近巡猎记录 |

召唤生成现有类型的孽兽、域外邪魔或外道修士，仍使用正常讨伐与奖励流程；不直接发放战利品，也不直接召唤灾厄魔主。

普通灾厄沿用全服100尊存世上限和原有巡猎机制。超额时优先清理实际生成时间更早的目标（按 `spawnedAt` 排序），世界回拨不会把新生成目标误判为旧敌；正在交战的目标及已锁定的玩家战利品仍按原规则保护。

手动召唤采用独立批次，不推进时代、不增加或扣除自然年累计，也不占用自然降临的批次记录；玩家讨伐冷却继续沿用原规则。

## 自然降临与时代回拨

普通域外灾厄按**自然流逝累计年份**生成：每累计满1000年，降临一批1～10尊。未满1000年的零头继续保留，自然累计不足1000年时不生成新的一批。

升级后，旧配置缺少自然累计字段时从0开始记录，不根据已有世界年份追补灾厄。

这个累计独立于当前世界年份。将世界回拨到早年，不会清空已累计的自然年份；再次自然流逝满1000年仍会降临，不按旧世界年份的千年记录阻止新一批。

例如：先自然流逝600年，再将时代回拨，随后自然流逝400年，累计正好1000年，触发一批灾厄。回拨本身不计年；若回拨后仅自然流逝300年，累计900年，尚不触发。

`#设置时代`、`#下一千年`、`#下一个时代`、玩家技能推进或改写时代等手动操作，不增加这份自然累计，也不直接触发自然灾厄。管理员 `#召唤灾厄` 始终独立：例如自然累计600年时手动召唤，累计仍为600年，再自然流逝400年才触发下一批自然降临。

验证记录（2026-10-12）：灾厄相关50项测试通过，覆盖管理员权限、数量校验、独立批次、并发、上限巡猎与异常提示；整插件隔离回归2328项通过、0失败、5项既有跳过。未在实服执行召唤，重启机器人加载后可用。

自然计时改造验证：相关92项测试中91项通过、1项既有跳过；整插件隔离回归2344项通过、0失败、5项既有跳过。覆盖回拨后600+400自然年、跨世界千年但自然不足、满100尊后的新批次保留、旧生成记录兼容、保存中断重试与配置旧快照保护。未修改在线时代或清理真实灾厄，重启加载新代码后开始使用独立自然累计。
