# 花粉进化路衔接与结算修复

本次修复花粉路线的地图衔接、高阶提示、旧存档识别与进化保存，不调整原战斗装备公式、材料价格或进化概率。

- 小阴间法则仍容纳至映照诸天；主修花粉达到11级后可先进入大阴间，再冲击神祇。阳间法则仍容纳至大宇／究极；主修花粉达到17级后可先进入仙域，再冲击宇究。其他体系的原通行条件、坐标、费用与耗时保留。
- 花粉高阶页面统一显示实际晋升入口：道祖经 `#推演己道` 到路尽，路尽经 `#祭道`，祭道依原始祖永祭与空间泡影规则，祭道之上沿原 `#证道` 流程。此处保留当前仓库已认主大道至宝的原证道条件，不引入新的终局系统。
- 高阶花粉悟道、专属渡劫和祖种仍可作为额外修持；页面不再把它们误写为已由其他入口负责的强制晋升步骤。祖种不是普通进化的必需品。
- 底层普通进化与高阶突破函数在专用晋升节点直接返回指引，避免其他调用方绕过高阶流程。
- 明确选择花粉且已开始进化的旧档，即使保留其他体系历史等级，也只继续花粉修炼；历史等级和属性计算保留，不开放新的兼修。未明确选择的混合档继续提示冲突。
- 普通进化的媒介扣除、境界与惩罚、属性重算纳入同一保存事务；写入异常回滚，不留下扣了材料却没记境界的半笔记录。原真实失败概率和惩罚保持。

回归覆盖地图门槛、低一级拒绝、高阶入口一致性、旧档兼容、进化成功/失败、并发、写盘异常恢复与既有属性保持。
