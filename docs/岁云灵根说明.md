# 岁云灵根

## 入门

在 **往世星海** 获取【岁云的残念】，独立触发概率为 `0.00001`（十万分之一，0.001%）。残念和灵根按时间线唯一；【无上天阙枝】跨全部时间线唯一。唯一物品不受物品倍率复制。

1. `#消耗岁云的残念`（兼容使用、服用、炼化）获得【月华之体】，天资改为【岁云】，并领取《月华炼天功》秘籍。
2. `#学习月华炼天功` 按现有功法学习流程习得。
3. `#岁云之力` 查看阶段、月华值、本源和岁云之力。

## 幸运、岁云剑灵与秘境通行

- **灵根幸运**：五个阶段自带100个百分点幸运（内部加成1），与福源丹和幸运仙宠的正常加成叠加。来源单独记录，重复读取、换宠或同步不会反复增加；离开岁云灵根时移除这份加成。
- **岁云剑灵（原霜月剑灵）**：晋升第三阶段【霜月剑尊】获得仙宠【岁云剑灵】一只；后续阶段及已晋升的旧角色可通过 `#岁云见证` 或 `#岁云之力` 补领，每个角色只发放一次。仙宠进入纳戒，使用 `#出战仙宠岁云剑灵` 出战，保留原先出战宠物。
- **三能力**：岁云剑灵同时具备战斗、炼器与炼丹能力。战斗侧保留等级1、等级上限100、每级加成0.35，基础atk/def/HP为20/7/15；炼器、炼丹各以 `附加能力` 成长值0.4参与现有计算。炼丹侧等同额外40%双倍出丹判定，不直接额外增加40%产量。三项并存，不占用或覆盖 `炼妖继承能力` 槽。
- **旧档迁移**：持有「霜月剑灵」或旧版「岁云剑灵」的存档在 `#岁云见证` 或 `#岁云之力` 时补齐炼器、炼丹能力，旧名统一为「岁云剑灵」。纳戒、出战与栖息地全部落盘，已领取标记不阻止能力迁移，保留等级、其他附加能力和炼妖继承，不重复发宠。

- **霜月套装**：第三阶段领取【霜月剑】【霜月剑袍】【霜月之莲】，绑定本人、进入纳戒，使用现有装备指令穿戴。霜月剑尊及后续阶段穿齐三件时，套装层攻、防、生命总倍率10倍（加成+9）；不是每件各加10倍，也不额外翻倍元神或其他资源。老角色通过 `#岁云见证` 或 `#岁云之力` 补领，发放中断按三件独立回执补齐，不重复发放。默认基础数值低于最终岁云套，不覆盖正在穿戴的装备。
- 仙宠采用现有“战斗”类型，名称与初始数值沿用既有默认设定；不是幸运型宠物，灵根的100%幸运独立生效。
- **秘境通行**：从霜月剑尊起，由灵根直接免除秘境入场资源消耗，涵盖单次、沉迷及法身入口；无需让赠送仙宠出战。原有境界、地点、冷却、行动、历练时长与战斗结算继续生效；位面传送等独立玩法不在此范围内。

## 灵根自带战技

**PVP同境裁决**：岁云五阶段本人在真人PVP中，对手的额外体系等效权柄高于自己时，强制把对手本场战斗中的秘境、仙古、花粉境界压至同等权柄，先于境界天堑与行动速度初始化。不同体系按已有等效境界映射，不直接比较原始编号；同境和更低境界的对手不变。只改变战斗境界及其派生判定，不把对手已经持有的攻防血面板改成自己的数值。比武、切磋、打劫、玩家炼化/搜魂、职业真人目标、天帝榜真人及仙古PVP入口明确接入；NPC、幻影、天骄、秘境、团本、试炼等PVE保持原规则。该被动不通过月华三技赐予，不由NPC或召唤物继承，原存档与返回的主角色境界保持真实值。

四种战技由**月华之体至岁云剑尊的全部五阶段**自带，进入战斗自动生效，不需要学习秘籍，也不占攻击、防御或生机技能槽；《月华炼天功》仍仅作为炼化的前置功法。

可用 `#我的战斗技能` 查看四种战技；切换到非岁云灵根后不再生效。

- `#月华锁魂`：岁云五阶段自带的搜魂技能。先战胜天骄，在求饶或处置窗口内使用，锁定本源后必定搜魂成功，跳过神魂自爆与反噬，不要求魔道值或《搜魂大法》。按原天骄搜魂奖励随机学习一门未掌握的功法；若已全部掌握，则增加元神上限的5%元神（至少1点）。本世道身结算死亡，不另发月华炼化奖励，同一份本源只选一种处置；写入失败可按原指令续结算。
