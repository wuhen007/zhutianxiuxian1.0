# 岁云灵根

## 入门

在 **往世星海** 获取【岁云的残念】，独立触发概率为 `0.00001`（十万分之一，0.001%）。残念和灵根按时间线唯一；【无上天阙枝】跨全部时间线唯一。唯一物品不受物品倍率复制。

1. `#消耗岁云的残念`（兼容使用、服用、炼化）获得【月华之体】，天资改为【岁云】，并领取《月华炼天功》秘籍。
2. `#学习月华炼天功` 按现有功法学习流程习得。
3. `#岁云之力` 查看阶段、月华值、本源、试炼进度和岁云之力。

晋升统一使用 `#岁云见证`。月华之体先完成三重顺序试炼，再达到仙台大能晋升：

- `#引月入体`：12次胜利；每现实小时可尝试一次，失利同样进入冷却。
- `#化霜入剑`：12场剑道试炼。
- `#月之见证`：9场见证。

失败保留已完成进度。后续三阶段仅检查相应境界；未添加需求之外的月华消耗或试炼。

岁云化身获得岁云法则。岁云剑尊的灵根攻、防、生、修炼效率和法球倍率对齐如梦本尊，并接入圆神奖励效果；奖励绑定【岁云袍】【岁云剑】【云月之莲】，以及自动认主并装备到至宝槽的【无上天阙枝】。原至宝保留到纳戒。结算中断可再次发送 `#岁云见证` 补结算，不重复发奖。

## 灵根自带战技

三种战技默认由**月华之体至岁云剑尊的全部五阶段**自带，进入战斗自动生效，不需要学习秘籍，也不占攻击、防御或生机技能槽；《月华炼天功》仍仅作为炼化的前置功法。原设定未指定战技解锁阶段，因此采用五阶段共有的默认值。

可用 `#我的战斗技能` 查看三种战技；切换到非岁云灵根后不再生效。

| 战技 | 效果 |
|---|---|
| 霜剑入月 | 最多攻击9个敌方单位，每个目标连续9击（最多81击），每击为当前攻击的25倍、无衰减且不可防御；每次施展对各目标附带绝对控制1次行动、行动条推退2500，并施加霜寒 |
| 岁云归一 | 防御反伤：承受的可减免伤害降低50%，再将**实际承受伤害的100%**反弹给攻击者；反伤不连锁反弹 |
| 白云苍狗 | 每场最多复活3次；每次攻击、防御、生命上限和速度分别乘1.5，三次累计复活增幅为3.375倍 |

- **霜寒**：持续本场战斗，每个全局回合结算一次，使目标当前生命、攻击、防御和速度各乘0.8；不降低生命上限。多次命中只保持霜寒状态，不因9连击叠加9份。绝对控制不受普通免控抵挡。
- **不可防御**：霜剑入月绕过防御属性公式和防御技能，仍走现有护盾及最终扣血结算；岁云归一的被动减伤仍参与结算。
- 白云苍狗的“全属性”仅指上述四项战斗属性，不翻倍元神资源、道果、暴击或其他存档属性；复活次数和临时增幅在新一场战斗重置。
- 岁云归一的50%减伤、100%实际伤害反弹，以及霜剑入月的2500推条（半条）、1次行动控制、霜寒每全局回合一次，是原设定未给出具体数字或结算方式时采用的明示默认值。推条按每次施展一次，而非每一击一次。

## 月华与本源

- `#云月修炼`：24小时一次，随机获得2000～5000点月华值。
- `#月华炼化 @玩家`：群内发动战斗，获胜后获得100～300月华；沿用现有本源保护、禁术共享冷却、弱者保护及行动互斥。
- `#月华炼化 天骄`：消费当前已镇压、仍待处理的天骄求饶记录，真实结算其本世道身；仅输入一个名字不会产生奖励。
- `#月华炼化 灾厄` / `#月华炼化 魔主`：消费本人讨伐获胜后5分钟内的本源凭证；与天魔炼化共用去重记录，一份本源仅结算一次。

炼化需要已习得《月华炼天功》。**天骄与灾厄每份本源增加其生命本源的10%（向下取整，至少1点），最高到当前阶段上限。**这是原需求未指定单次增长量时采用的明示默认值；玩家炼化只获得月华，不增加本源。晋升后本源切换为新阶段基础值，再继续炼化成长。

## 云月之莲成长

`#云月之莲` 查看累计炼化月华、莲花成长数值和当前是否生效。**每累计炼化获得1点月华，云月之莲额外提供攻击、防御、生命上限各20万点固定属性。**例如一次炼化获得100月华，三项属性各增加2000万；获得300月华则各增加6000万。原需求未指定单点成长量，这里采用与万灵魔幡单魂2000万三围增幅相呼应的默认值。

- 只累计成功 `#月华炼化` 玩家、天骄或灾厄实际获得的月华；同一份本源重复结算不重复成长。`#云月修炼` 和直接修改月华余额不计入累计。
- 累计炼化月华独立于可消费的月华余额：兑换岁云之力或其他月华消耗不扣成长，阶段晋升也不清空累计；未设置游戏内成长上限。
- 成长可在获得法宝前积累；取得【云月之莲】后，须装备到**法宝槽**且持有岁云灵根才生效。卸下或切换非岁云灵根时增幅停止，累计仍保留。
- 三项成长为最终固定加算，不再被套装倍率重复放大；装备原始品质、重铸和归一属性保留，反复查看或重算不产生复利。
- 旧存档缺少累计字段时从0开始记录，不按现有月华余额或历史炼化次数猜测补发。已有云月之莲继续使用，无需重新领取。

## 月华天宫与岁云之力

已有小世界在觉醒时升华；先觉醒再开辟时自动升华。尚未开辟小世界不积累产出。

- 每**现实整小时**获得0.5点岁云之力，不乘小世界时间流速。
- 使用 `#岁云之力`、岁云更改命令或 `#收获小世界资源` 时结算累计产出，保留未满一小时的时间；无需分身。
- `#岁云之力 兑换 10000`：10000月华兑换0.1点岁云之力，可填10000的正整数倍；省略数量按10000兑换。
