# 岁云灵根

## 入门

在 **往世星海** 获取【岁云的残念】，独立触发概率为 `0.00001`（十万分之一，0.001%）。残念和灵根按时间线唯一；【无上天阙枝】跨全部时间线唯一。唯一物品不受物品倍率复制。

1. `#消耗岁云的残念`（兼容使用、服用、炼化）获得【月华之体】，天资改为【岁云】，并领取《月华炼天功》秘籍。
2. `#学习月华炼天功` 按现有功法学习流程习得。
3. `#岁云之力` 查看阶段、月华值、本源、试炼进度和岁云之力。

晋升统一使用 `#岁云见证`。月华之体先完成三重顺序试炼，再达到仙台大能晋升：

- `#引月入体`：12次胜利；每现实小时可尝试一次，失利同样进入冷却。
- `#化霜入剑`：12场剑道试炼。

## 幸运、霜月仙宠与秘境通行

- **灵根幸运**：五个阶段自带100个百分点幸运（内部加成1），与福源丹和幸运仙宠的正常加成叠加。来源单独记录，重复读取、换宠或同步不会反复增加；离开岁云灵根时移除这份加成。
- **霜月仙宠**：晋升第三阶段【霜月剑尊】获得攻击型仙宠【霜月剑灵】一只；后续阶段及已晋升的旧角色可通过 `#岁云见证` 或 `#岁云之力` 补领，每个角色只发放一次。仙宠进入纳戒，使用 `#出战仙宠霜月剑灵` 出战，保留原先出战宠物。
- 仙宠采用现有“战斗”类型。名称与初始数值为本次默认设定：等级1、等级上限100、每级攻击加成0.35，基础atk/def/HP为20/7/15；不是幸运型宠物，灵根的100%幸运独立生效。
- **秘境通行**：从霜月剑尊起，由灵根直接免除秘境入场资源消耗，涵盖单次、沉迷及法身入口；无需让赠送仙宠出战。原有境界、地点、冷却、行动、历练时长与战斗结算继续生效；位面传送等独立玩法不在此范围内。

## 灵根自带战技

四种战技由**月华之体至岁云剑尊的全部五阶段**自带，进入战斗自动生效，不需要学习秘籍，也不占攻击、防御或生机技能槽；《月华炼天功》仍仅作为炼化的前置功法。

可用 `#我的战斗技能` 查看四种战技；切换到非岁云灵根后不再生效。

### 月华赐予

- `#赐予月华 @目标`：当前持有任一岁云阶段灵根的修士，可以将【霜剑入月】【岁云归一】【白云苍狗】一并授予另一名玩家。
- `#赐予月华`：查看全服受赐席位。**全服最多3名受赐者，永久占席，不支持撤销后换人。**同一玩家重复受赐不重复占席，也不重复增加技能。

- 受赐战技绑定本人，随本人切换诸天化身仍保留；不走普通功法学习或传功，不随召唤物复制，不可转授。

## 绝灵被动、岁岁年年与岁云殿堂

五阶段直接免疫绝灵时代的纳戒侵蚀、因果绝灵侵蚀和寿元压制，不依赖岁云常青技能；旧档已有压制寿元在正常存档读取、写入时恢复。月华受赐者不获得这项灵根被动。

`#岁岁年年` 每现实小时领取1件，不填物品随机获得九大仙金之一、潜力丹、大衍悟道丹或悟道古茶叶；可指定 `材料` / `潜力丹` / `大衍悟道丹` / `悟道古茶`，也可填写完整仙金名。九大仙金池采用现有仙泪绿金、凰血赤金、龙纹黑金、永恒蓝金、神痕紫金、道劫黄金、羽化青金、太阴天金、太阳天金。每次固定1件，不叠物品倍率；发放中断同时恢复物品和冷却。

`#刻舟求剑` 进入专属秘境【岁云殿堂】，五阶段均可从当前所在位面叩门，免灵石与寿元入场消耗。沿用普通秘境实际耗时、行动互斥、战斗、奖励与法身结算；不开放沉迷入口。低级奖励群星圣药，中级奖励岁月的馈赠，高级奖励池为潜力丹、大衍悟道丹、悟道古茶叶，掉落数量沿用当前岁云阶段的秘境倍率。

【岁月的馈赠】按现有丹药服用指令使用，效果与【如梦的加持】一致：出金率增加50个百分点，生效次数与叠加限制沿用现有出金率丹药规则。

`#月华垂钓`：岁云五阶段在群内消耗3点岁云之力，直接钓起鱼王并自动成为垂钓者，无需鱼钩或饵料，也不另设钓鱼冷却。实体位面钓起当前水域的鱼王，未登记水域的抽象位面随机连通已有鱼王水域；使用现有鱼王编号、组队、讨伐及奖励流程。本群已有鱼王、本人已在其他鱼王队伍、岁云之力不足或创建中断时不消耗本次3点。天宫产出先独立结算，再扣本次垂钓费用。

管理员 `#复苏厄土高原`（兼容 `#复苏额土高原`）恢复高原，清除祭道之上留下的永久覆灭、祭礼状态中的高原终结与旧大祭终结标记。无角色境界或资源要求；保留祭礼历史计数，重新安排后续周期，不重发首次援军，不自动修复其他位面或发放奖励。普通映照和自然修复仍遵守原来的永久覆灭限制。

## 月华与本源

- `#云月修炼`：24小时一次，随机获得2000～5000点月华值。
- `#月华炼化 @玩家`：群内发动战斗，获胜后获得100～300月华；沿用现有本源保护、禁术共享冷却、弱者保护及行动互斥。
- `#月华炼化 天骄`：消费当前已镇压、仍待处理的天骄求饶记录，真实结算其本世道身；仅输入一个名字不会产生奖励。
- `#月华炼化 灾厄` / `#月华炼化 魔主`：消费本人讨伐获胜后5分钟内的本源凭证；与天魔炼化共用去重记录，一份本源仅结算一次。除原有月华、本源和云月之莲成长外，另获以下修行收益。

| 灾厄／魔主额外收益 | 单份本源结算规则 |
|---|---|
| 修为 | 炼化前当前修为的2%，向下取整，至少1点 |
| 血气 | 炼化前当前血气的2%，向下取整，至少1点 |
| 元神 | 炼化前当前元神的1%，向下取整，至少1点；不增加元神上限 |
| 生命本源 | 与天魔炼化共享来源抽取算法：来源本源保留1点，抽取剩余部分的20%并乘炼化权重；普通灾厄权重0.1，魔主0.5。结果保留3位小数，再按岁云当前阶段成长上限裁剪 |
| 仙道潜力 | 与本次生命本源**实际增加量等量**，可保留3位小数；本源已封顶时增加0，不按现有仙道潜力再次计算百分比 |

修为、血气、元神和生命本源复用天魔炼化灾厄的同源计算函数，月华炼化不增加魔道值、不改变元神上限。仙道潜力按本源实增等量发放是月华炼化的额外规则；现有天魔炼化奖励内容不因此改动，也不另建“元神潜力”资源。以上只适用于成功炼化**灾厄或魔主**，不扩展到天骄、玩家炼化或每日云月修炼，也不乘物品获取倍率。重复凭证、重复请求或结算重试不重复发放；原有100～300月华与云月之莲累计成长保留。

灾厄本源精确计算：先将来源本源规范为 `max(1, Number(来源本源) || 100)`；可抽取量为 `max(0, floor(来源本源) - 1)`；抽取值为 `min(可抽取量, max(1, floor(可抽取量 × 20%)))`；乘权重后四舍五入保留3位小数，最终增加量受岁云阶段剩余容量限制。例如来源本源100的普通灾厄，抽取19再乘0.1，未触及阶段上限时生命本源与仙道潜力各增加1.9。

炼化需要已习得《月华炼天功》。**天骄仍按其生命本源的10%增加本源（向下取整，至少1点），最高到当前阶段上限；不追加上述灾厄专属资源奖励。**这是原天骄单次增长量采用的明示默认值；玩家炼化只获得月华，不增加本源。晋升后本源切换为新阶段基础值，再继续炼化成长。

## 云月之莲成长

`#云月之莲` 查看累计炼化月华、莲花成长数值和当前是否生效。**每累计炼化获得1点月华，云月之莲额外提供攻击、防御、生命上限各20万点固定属性。**例如一次炼化获得100月华，三项属性各增加2000万；获得300月华则各增加6000万。原需求未指定单点成长量，这里采用与万灵魔幡单魂2000万三围增幅相呼应的默认值。

- 只累计成功 `#月华炼化` 玩家、天骄或灾厄实际获得的月华；同一份本源重复结算不重复成长。`#云月修炼` 和直接修改月华余额不计入累计。
- 累计炼化月华独立于可消费的月华余额：兑换岁云之力或其他月华消耗不扣成长，阶段晋升也不清空累计；未设置游戏内成长上限。
- 成长可在获得法宝前积累；取得【云月之莲】后，须装备到**法宝槽**且持有岁云灵根才生效。卸下或切换非岁云灵根时增幅停止，累计仍保留。
- 三项成长为最终固定加算，不再被套装倍率重复放大；装备原始品质、重铸和归一属性保留，反复查看或重算不产生复利。
- 旧存档缺少累计字段时从0开始记录，不按现有月华余额或历史炼化次数猜测补发。已有云月之莲继续使用，无需重新领取。

## 岁云造物

仅第五阶段【岁云剑尊】本源可用：`#岁云造物 物品名`，也支持名称紧贴指令，例如 `#岁云造物无上九转仙丹`。先结算月华天宫产出，再按余额消耗**10点岁云之力**，固定生成**1件**物品到自己的纳戒。

- 稀有度不设上限，8、9、10级的普通物品也可创造；物品须存在于当前目录且支持入纳戒。

- 参数错误或余额不足不扣造物费用；发放失败时回滚本次费用和物品。装备品质按普通入纳戒流程随机生成，不保证顶级品质。
