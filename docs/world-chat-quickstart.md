# 世界聊天：加入群、跨服发言与排查

## 三步开始

1. 更新插件、安装依赖并重启机器人。
2. **在需要接收消息的群里**，由群主、群管理员或机器人主人发送 `#加入世界聊天`（旧指令 `#世界加入` / `#世界 加入` 继续有效）。
3. 发送 `#世界状态`。总机显示已连接且本群已加入后，即可接收其他区服的世界发言；成员用 `#世界发言 你好` 主动发送跨服消息。

`#修仙帮助`、`#诸天帮助` 已列出世界聊天菜单；`#世界帮助`、`#世界聊天`、`#世界频道帮助` 可以直接查看文字步骤和当前状态，无需创建修仙存档。

## 安装后的自动连接

- 客户端默认尝试连接配置中的公共总机，连接断开会自动重连。首次接入需有效的登记配置，成功后每台独立安装保存自己的身份。
- **自动连接总机**与**往 QQ 群转发消息**是两件事：只有管理员明确加入的群才会转发，加入记录会持久化；重启后不必反复加入。
- 本次不自动枚举或加入机器人所在的全部群，不转发普通群聊。需要跨服发送时使用 `#世界发言 内容`，可附图片。
- 默认不会公开群号；跨服交易仍按原来的开关和双方许可校验。世界聊天与公共世界携档迁移无关，不会导入或移动玩家存档。

## 常用指令

| 指令 | 用途 | 权限 |
| --- | --- | --- |
| `#世界帮助` / `#世界聊天` | 查看菜单与接入提示 | 所有人 |
| `#加入世界聊天` / `#世界加入` | 当前群订阅跨服消息 | 群主、群管理员、机器人主人 |
| `#退出世界聊天` / `#世界退出` | 停止当前群接收 | 群主、群管理员、机器人主人 |
| `#世界发言 内容` | 主动向世界频道发言，可附图片 | 已加入群的成员 |
| `#世界查看 10` | 查看最近消息 | 沿用原频道权限 |
| `#世界状态` | 核验连接及当前群订阅 | 所有人；详细身份诊断仅主人私聊 |
| `#世界网页` | 获取个人世界网页入口 | 已加入群的成员 |
| `#世界开启` / `#世界关闭` | 显式设置全局频道开关 | 机器人主人 |
| `#世界开关` | 旧的切换开关，继续兼容 | 机器人主人 |
| `#世界改名 我的区服` | 修改区服昵称 | 机器人主人 |

`#世界开启` 重复执行不会把频道关掉；`#世界关闭` 不清除已加入群记录。群管理员的“加入”不会覆盖机器人主人关闭的总开关。

## 已加入但没有消息

加入回复现在分别显示“订阅已保存”和总机状态，不再把保存订阅当成已经连通。

1. 频道总开关关闭：让机器人主人发送 `#世界开启`。
2. 身份登记尚未通过：机器人主人**私聊** `#世界状态` 检查登记错误；确认本机接入配置或 `WORLDCHAT_ENROLLMENT_TOKEN` 是否有效。凭据向总机管理员取得，勿贴进群聊、公开日志或提交本机运行时配置。
3. 总机登记限流：等待客户端自动重试，避免重复重装或复制身份文件。
4. 连接中/鉴权中：等连接完成再发送 `#世界状态`；检查服务器网络、WebSocket/TLS 连通性。
5. 已连接但机器人账号未上线，或机器人在群内被禁言：恢复机器人账号和发送权限；总机在线不等于 QQ 发送成功。
6. 首次加入从当前消息开始订阅，不会把加入之前全部历史倒进群。测试时请让另一个已连接区服发送一条**新的** `#世界发言`。

搬机器时避免多人共用同一份运行时 `server_id/secret/installation.id`；每个独立设备应完成自己的登记。不要从其他人的目录直接拷运行身份，也不要把接入令牌放进截图或群发。
