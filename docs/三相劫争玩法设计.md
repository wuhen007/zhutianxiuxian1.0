# 三相劫争：三阵营隐藏身份玩法设计

日期：2026-11-03（北京时间）

状态：玩法设计稿。本文定义规则、身份、交互与接入方案，尚未新增游戏命令、网页入口或线上活动。人数、时段与奖励倍率均为首测建议值。

## 1. 核心玩法

在独立的劫境投影中，玩家随机加入修士、天魔、异类三大阵营。通过个人通行私钥绑定本局身份，私下查验、护持、刺杀、伪装或转化其他玩家。

修士靠情报与爆发，天魔靠侵蚀与夺舍，异类靠拟态与反制。玩家可以公开讨论、结盟、说谎，但真实身份卡由服务端保管。

**胜利条件：场上只剩一个阵营存活。清掉一个敌对阵营后继续，另外两个阵营均无存活成员时才结算。** 剩余人数占优、到达活动时限、击杀最多均不直接判胜。

- 每人一条生命；死亡仅影响本局投影，角色本体、纳戒与修为照常保留。
- 死者退出行动，但保留死亡时的阵营。该阵营最终获胜，死去的队友同样领取基础胜利奖励。
- 退游、断线不等于死亡；活动进行中退出按阵亡处理，保留死亡时阵营，不可重新报名本局。
- 仅剩一名存活者也可带领所在阵营获胜；全体同时死亡则为同归于尽，无胜方奖励。
- 开局后固定参赛名单，结束前不补人、不复活已灭绝阵营。
- 不继承本体战力、灵根、至宝或付费加成，所有胜负因素来自本局规则。

推荐首测采用十二人局，每个阵营四人；支持九、十二、十五、十八人预设，各阵营人数相等。人数更少的房间可作练习局，首测暂不开数值奖励。

## 2. 私钥、身份与信息边界

### 2.1 绑定流程

1. 群内创建房间、报名；每个游戏账号同一时间只参加一局。
2. 玩家通过机器人私聊领取本局通行私钥。建议采用密码学随机的三十二字节令牌。
3. 私聊提交私钥，绑定当前游戏账号与本局席位。系统按报名账号核对，转发别人的私钥也不会接管其席位。
4. 绑定后私下查看身份、使用技能、读取个人战报。私钥轮换撤销旧绑定会话，角色、冷却、次数与已发生的结果保持原样。
5. 开局前全部玩家完成绑定，避免有人连自己的身份都没看到就被淘汰。

这里的“私钥”是本玩法的个人通行令牌，不使用玩家的钱包私钥或其他平台凭据。服务端仅存令牌摘要，原文仅在领取或重置时私发；群聊、URL、公共日志均不携带原文。

当前源码中的无尽网页使用一次性票据与 Redis 会话；本次检索尚未发现可直接复用的“玩家私钥绑定身份”模块。实现时可复用会话机制，另加本玩法的房间凭据校验。

### 2.2 各类界面能看什么

| 入口 | 显示内容 |
| --- | --- |
| 公共房间 | 房间号、规则、初始配比、席位与道号、存活/死亡、当前时段、总存活人数、匿名事件 |
| 我的身份 | 自己的真实身份、当前阵营、拟态、劫伤、护持、侵蚀、技能次数与冷却、私人战报 |
| 技能情报 | 按技能权限给施法者结果；普通查验可能受到拟态影响 |
| 结算 | 公共宣布胜利阵营与活动结束；个人收益私下展示 |

真实身份默认只在本人面板出现。神算等查验技能是规则内的信息获取渠道，结果也只交给施法者。其他人的真实身份、阵营人数变化、私钥摘要、私人战报，不进入公共响应。

同阵营成员开局也不自动互认。玩家自行交换信息、试探和建立信任。死亡时不公开身份；结束后也不默认公开全员身份表。

公共事件采用“七号席位陨落”“劫境发生异动”等文案，避免用技能专属名称直接泄露施法身份。

## 3. 时间、行动与基础战斗

### 3.1 一天的定义

**“一天一次”统一按使用后连续二十四小时恢复。** 不在零点统一清空冷却，避免跨零点连用。剩余时间由服务端计算，统一按北京时间展示。

普通斗法、身份主动技、异类拟态分别计时；全局每局次数、天魔转化名额单独记录。夺舍、拟态、转化或重新绑定均不刷新已经花掉的冷却和次数。

### 3.2 人人可用的普通斗法

为避免最后只剩辅助身份时互相耗住，每个存活玩家都有普通斗法：

- 每二十四小时一次，指定一个其他存活席位，造成一层劫伤。
- 两层劫伤触发死亡判定。成功免死后劫伤清为零。
- 剑斩、噬魂等致命技能直接触发死亡判定，无须先叠劫伤。
- 允许误伤同阵营；选人界面与提交前校验不提示目标是否为队友。
- 普通攻击与身份主动技独立计时，辅助也能推进战局。
- 使用前显示目标席位并二次点击确认，避免触屏误杀。

普通斗法结算只向施法者反馈行动已结算、目标是否死亡；不主动披露目标的护盾来源、角色或当前阵营。本人可以看到自己承受的攻击与被消耗的防护。

### 3.3 三个优势时段

全天都可行动，优势时段给予确定效果，不采用攻击随机落空。

| 北京时间 | 优势阵营 | 首测加成 |
| --- | --- | --- |
| 06:00—14:00，清明天 | 修士 | 神算查验带真视，识破拟态；每名修士另可发动一次清心，清除自己一层劫伤，清心独立冷却二十四小时 |
| 14:00—22:00，万相天 | 异类 | 每名异类可额外调整一次自己的拟态；另可发动一次蜕皮，抵挡下次普通斗法，蜕皮独立冷却二十四小时 |
| 22:00—次日06:00，天魔夜 | 天魔 | 此时施加的魔种由六小时缩短至四小时成熟；夺舍可指定尚未受伤的敌方目标 |

清心不复活、不解除魔种；蜕皮不抵挡剑斩、夺舍或转化。额外拟态调整独立冷却二十四小时，仍使用当前拟态的原到期时间。

优势按行动被服务端接受的时间判断。跨时段不会重发已用的恩赐，后续阵营变更也不会重置恩赐记录。

## 4. 修士身份

修士共六种身份。十二人首测固定神算者、剑修、体修，再从丹师、阵师、镇魔使中随机加入一名。

| 身份 | 能力 | 冷却与边界 |
| --- | --- | --- |
| 神算者 | 天机推演：查一人的身份与当前阵营 | 二十四小时一次。清明天为真实结果；其他时段读取表象，并明确标注“可能受到拟态干扰” |
| 剑修 | 一剑断命：向一名玩家发起致命攻击 | 默认二十四小时。真正斩死当前敌对阵营玩家，立即恢复剑斩；误杀友军、目标免死或只有劫伤时均不刷新 |
| 体修 | 不灭金身：被动抵消一次死亡 | 触发后冷却二十四小时；抵消时清空劫伤。死亡后不再恢复，不抵抗阵营转化 |
| 丹师 | 回春：清除一名存活者的一层劫伤，并清除尚未成熟的魔种 | 二十四小时一次，可选自己；没有复活效果 |
| 阵师 | 护命阵：为一名玩家布置一次免死护持 | 二十四小时一次，护持持续二十四小时；同类护持最多一层，连续两次施法须选不同目标 |
| 镇魔使 | 镇邪印：清除目标拟态与未成熟魔种，并令其十二小时内免受新的魔种 | 二十四小时一次；不撤销已经完成的转化，不向施法者公布目标阵营 |

### 剑修保留原始爽点

剑修没有每日斩杀数量上限。只要每次都真正斩死敌方，就可以继续斩下一人。

敌我关系以致命攻击结算前的真实当前阵营判断，拟态不会改变敌我关系。已经转成天魔的修士被修士剑修斩死，属于敌方击杀；伪装成天魔的异类被异类阵营剑修斩死，属于误杀友军。

对同一行动必须先结算免死、反制和最终死亡，再决定是否刷新，避免对着体修或护命阵无限刷技能。

## 5. 天魔身份

天魔共六种身份。十二人首测固定夺舍魔君、种魔者，再从另外四种中随机加入两名。

| 身份 | 能力 | 冷却与边界 |
| --- | --- | --- |
| 夺舍魔君 | 夺舍：对带劫伤的敌人发起致命攻击，若成功使其死亡，获得其身份的主动技能，替换自己的夺舍技 | 每局一次；天魔夜取消受伤前提。防护拦截则夺舍失败，次数照常消耗；保留目标技能已用次数与冷却 |
| 种魔者 | 植入魔种：目标经过侵蚀期后转为天魔 | 二十四小时一次；通常六小时成熟，天魔夜施种四小时成熟；受阵营总名额约束 |
| 噬魂者 | 噬魂：对已经带有劫伤的玩家发起致命攻击 | 二十四小时一次，受免死防护影响；成功击杀后清除自己一层劫伤 |
| 魇魔 | 梦魇：封住目标身份主动技八小时 | 二十四小时一次；不封普通斗法、拟态与体修被动，不改变已提交的行动 |
| 血祭使 | 血祭：自己增加一层劫伤，为另一人布置一次免死护持 | 二十四小时一次；自身因此触发死亡时照常结算，护持仍生效；与护命阵共用一层上限 |
| 蚀心魔 | 蚀心：令目标十二小时内下一次受到的普通斗法额外增加一层劫伤 | 二十四小时一次，同一目标最多一层；不提高剑斩等致命技效果 |

### 5.1 夺舍与账号绑定分开

夺舍取得的是局内身份能力。操作者、游戏账号、通行私钥和奖励收款人始终不变，施法者继续属于天魔；被夺舍者按死亡处理。

夺来的剑修可以靠斩死天魔敌人刷新技能。夺来的全局限次技能继承剩余次数，已用完的技能保持耗尽，避免夺舍后重置能力。

被动身份没有主动技能可取时，夺舍依然完成击杀，但不取得对方的被动免死；施法前规则中明确这一点。目标具体身份仍由击杀后私下获知。

### 5.2 转化必须有预警和反制

- 魔种施加后，目标立即收到私人侵蚀提示与成熟时间，可以向丹师、镇魔使求助。
- 目标在成熟前死亡，魔种消失；施种者在成熟前死亡，魔种随之消失。施种者死亡之前已完成的转化永久保留至本局结束。
- 只有存活的非天魔玩家可被转化；每名玩家整局最多成功转化一次。
- 转化保留玩家操作者、原始身份技能与既有冷却，更换当前阵营。转化后的剑修、神算、体修仍有原来的能力，按天魔阵营行动与结算。
- 十二人局天魔阵营最多成功转化两人；通用名额为 `max(1, floor(初始人数 / 6))`，全体天魔共享，死亡不返还名额。
- 施种时预占名额。魔种被清除、失效或目标提前死亡则释放预占；成功转化后永久消耗，防止多个魔种同时成熟越过上限。
- **最后一名敌对存活者仍需被击杀。** 魔种成熟时若该目标是场上最后一名非天魔存活者，魔种消散并释放预占名额，阵营保持原样。若仅消灭了修士、异类中的一方，另一方仍有人，继续对局。
- 同阵营、重复转化或受到镇邪保护等失败原因统一反馈“魔种未能建立”，不把选择技能当作免费查验。服务端在有效施法后统一消耗冷却。

强制转化是首测最需要观察的机制：目标的获胜目标立即改变，但所有行动仍由玩家本人决定；系统不替其操作，也不公开其身份。

## 6. 异类身份

所有异类都有“万相拟态”：每二十四小时可从完整身份表选一种表象，持续二十四小时，可在自己的面板取消。拟态改变普通查验得到的身份与表象阵营，真实阵营、胜负和奖励保持不变。

拟态不转移账号，不冒用其他玩家的名字，也不会自动获得拟态对象的技能。异类因此既能装成修士，也能装成天魔；清明天真视和镇邪印可以克制。

异类共六种身份。十二人首测固定拟形者、镜妖、替命傀儡，再从其他三种中随机加入一名。

| 身份 | 能力 | 冷却与边界 |
| --- | --- | --- |
| 拟形者 | 借法：按当前拟态借用一次查验、回春、护命或梦魇 | 四种对应神算者、丹师、阵师、魇魔；共用二十四小时冷却。查验采用普通表象结果，无清明真视；不借连斩、转化、夺舍或被动免死 |
| 千面狐 | 画皮：为另一名玩家指定一种虚假表象，覆盖十二小时 | 二十四小时一次；目标收到“表象被扰动”的私人提示；不改变其身份能力或真实阵营 |
| 镜妖 | 镜返：给自己准备一次反射普通斗法的效果，持续十二小时 | 二十四小时一次；触发时自己不受本次劫伤，施法者承受该次基础劫伤；不反射剑斩、魔种、夺舍或附加蚀心 |
| 替命傀儡 | 替命：为自己或另一名玩家挂一次免死护持 | 二十四小时一次，持续十二小时；与护命阵、血祭共用一层上限，连续两次须选不同目标 |
| 窃法灵 | 窃护：取走目标身上的一次可转移免死护持，移到自己身上 | 二十四小时一次；不窃取体修被动、镜返或蜕皮。自己已有同类护持时先拒绝施法，不消耗冷却 |
| 渡厄鸦 | 观厄：查看目标当前劫伤、可见防护种类与魔种剩余时间 | 二十四小时一次，私下反馈；不显示真实身份、阵营或施法来源，可帮助异类挑选破绽 |

万相拟态与身份主动技分开计时，切换表象不会多给一次借法。画皮、万相拟态冲突时，取最新生效的表象；镇邪清除两者，普通查验只读取当前有效表象。

## 7. 统一结算与终局

### 7.1 一次行动的处理顺序

同一房间内串行处理，所有状态变更在服务端完成：

1. 校验会话、房间、操作者、存活状态、目标、冷却与请求编号。
2. 按到期顺序处理已成熟的魔种、过期状态及其他定时效果；每个到期事件作为独立事件完成胜负检查。若已结束，停止后续行动。
3. 再次校验行动条件，固定本次行动开始时的真实阵营，扣除次数或冷却。
4. 结算镜返或蜕皮等针对普通斗法的前置抵挡；抵挡成功时不施加劫伤，也不消耗蚀心标记。
5. 未被抵挡时，施加基础劫伤及目标身上的蚀心附加劫伤，并消耗蚀心；致命技能直接进入下一步。
6. 触发死亡判定时，依次使用外部免死护持、体修被动；抵消一次死亡只消耗一个来源，劫伤清零。
7. 真正死亡后冻结其阵营、取消其未成熟魔种等依赖状态；再处理夺舍成功效果、剑修刷新。
8. 完成同一技能的所有后果后，统一检查胜负并保存状态、公共事件与相关私人结果。

血祭等包含多个后果的技能视为同一事件，不能在代价与收益之间提前判胜。失败的重复请求复用原结果，不重复扣次数、攻击或转化。

镜返只反射一次基础斗法，不触发第二次镜返。反射伤害落到原施法者时按普通受伤处理，其自身的蚀心可生效，防止递归反射。

外部免死护持最多一层，体修被动与其分开。若同时存在，先用外部护持；下一次致命攻击才可能触发金身。成功免死的具体来源只向本人展示。

### 7.2 胜负检查

按每个存活成员的**真实当前阵营**统计：

- 三个阵营仍有存活者：继续。
- 两个阵营仍有存活者：继续。
- 仅一个阵营有存活者：该阵营获胜。
- 全部死亡：同归于尽。

一旦冻结终局快照，后续请求和定时任务不再改写身份、死亡或胜方。待发奖励独立重试，游戏结果保持冻结。

### 7.3 防止永远打不完

体修每日免死、治疗和辅助互保可能拖成僵局，采用公开预告的劫境收紧：

- 开局满九十六小时：劫伤成为道伤，回春、清心、噬魂的自愈不再清除劫伤；丹师仍可解除未成熟魔种。
- 开局满一百六十八小时：进入终劫，普通斗法直接触发死亡判定；外部护持、体修金身、镜返、蜕皮全部失效，封术和未成熟魔种也不再生效。
- 终劫后死亡仍按真实阵营结算，必须打到只剩一个阵营或全灭；不按积分或时限指定胜方。
- 若无人再行动，房间保留待战状态，不把断线者自动判死。房主或管理员可以作废整局，但作废不产生胜方奖励。

终劫是防护退出机制，不是自动结束时间。

## 8. 胜利阵营奖励

### 8.1 奖励对象

胜利阵营每名成员领取同一档基础奖励，含此前阵亡的队友。死亡玩家按死亡时冻结的阵营，存活玩家按终局阵营。

例如：修士剑修转化成天魔后死亡，最终天魔胜，其按天魔成员领奖；转化前已经死亡的修士保持修士归属。

败方记录战绩，不发胜方数值奖励；挂机没有额外贡献奖励。首测不引入按击杀分走队友奖励的制度，保护查验、解种、护持等辅助贡献。

### 8.2 复用无尽奖励种类

建议基础胜利奖励包含：

- 灵石。
- 源石。
- 劫境道痕，直接使用现有余额字段与无尽商店。
- 修为、血气，按报名时保存的境界快照计算。
- 首胜纪念与累计胜场称号；首版称号仅用于展示，不增加本玩法战力。

货币基数建议取 `getEndlessLayerCurrencyReward(10)` 的单层结果，首测按该基数一倍发给每位胜方成员；这是建议预算，不代表已经完成经济平衡。

修为、血气沿用无尽现有的境界成长口径，以固定随机参数计算并封存在结算单。现有相关函数为模块内部函数，接入时先提取共享计算函数，再由两套玩法共同调用，避免复制公式后漂移。

奖励量不随房间拖延、互杀次数、阵营最终人数或天魔转化人数上涨；转化会增加天魔领奖人数，但整个房间发奖人数上限始终为初始报名人数。

十二人及以上、正常开局且满足胜利条件的首测房间发正式奖励。九人局可以玩完整规则，暂按练习局记录战绩；十八人以内使用同一人均基础档，先观察单位活动的总产出。

暂不直接套用无尽通关至宝、层数解锁、首通进度或限购扩容。三相劫争胜利不等于打穿无尽劫境，奖励接入不改写这些进度。

### 8.3 幂等、失败与防刷

- 使用独立结算编号 `three-realm:{roomId}:{runId}`，每个玩家保存独立的三相劫争结算记录。
- 终局先生成不可变的名单与奖励单，再逐人领取；玩家奖励数值、领取记录在同一次角色档案写入中保存。
- 房间标记已发放失败时，可从玩家记录恢复；单人写入失败保留待发状态，只重试未到账成员。
- 角色写入复用玩家变更锁，和商店、其他副本并发时从锁内读取最新角色再修改。
- 不以短期 Redis 锁充当永久发奖凭据。归档结算单与玩家收据需持久保留，旧结算不重新开放领取。
- 同一游戏账号跨群仍只能参加一局。活动中既有角色记录的转区、别名也应解析成统一游戏账号。
- 开局后禁止换号、替补与重抽身份。重置私钥只撤销凭据，不改游戏状态。
- 一人多号与线下串通属于运营问题，技术上只能增加门槛和审计；不宣称可彻底识别。首测先限房主开局频率与每账号每周三次正式获奖，额度耗尽仍可参加但只记战绩。
- 每周额度按周一零点北京时间归属，消耗发生在创建奖励单时，和结算编号绑定；领取重试不重复消耗。

## 11. 实装验收清单

- 私钥仅绑定原报名游戏账号；撤销、旧令牌、跨房间令牌、其他玩家会话均被拒绝。
- 公共状态、事件、异常与群聊回复不带真实身份、目标私人结果或凭据。
- 神算二十四小时冷却，清明真视与普通拟态结果均符合规则。
- 剑修连续斩敌刷新，误杀不刷新，免死不刷新；转化前后的敌我关系按真实阵营判断。
- 体修与外部护持每次只消费一个防护，二十四小时恢复不复活死者。
- 拟态改变表象、不改真实阵营；借法、夺舍和重新绑定不洗冷却或全局次数。
- 魔种预警、净化、施种者死亡、名额预占释放、到期转化、最后敌人保护逐项验证。
- 十二人局并发魔种不超过两次成功转化，异类伪装成天魔不改变这一判断。
- 消灭一个阵营继续，最后一个敌对存活者死亡才结束；同时全灭无胜方。
- 镜返不递归，血祭多个后果完成后才判胜；终局冻结后定时效果不改结果。
- 终劫按服务器时间生效，不提前结算；普通辅助身份也有推进终局的手段。
- 胜方阵亡队友领奖，死亡时阵营冻结，败方不领胜奖；转化者正确归属。
- 重复提交、进程重启、发奖中断、房间写入失败及玩家记录写入失败均不重复发奖。
- 正式局门槛、账号跨群互斥、每周获奖额度和新手私聊失败均有真实流程验证。

## 12. 首测重点

十二人局先使用各阵营四个身份，保持核心身份固定、其余随机，不一次把所有扩展身份混入小房间。

主要观察剑修平均连斩数、魔种解除率、转化成功率、各阵营胜率、首次死亡前行动机会和总时长。剑修保持击杀刷新与无连斩上限，优先通过护持、拟态、公开讨论时间及阵营配比做平衡。

若转化过强，先下调全阵营名额或延长侵蚀期；若异类过弱，先加强其情报与抵挡普通攻击的机会。所有调整都在下一局生效，开局冻结规则版本，避免局中修改改变玩家预期。
