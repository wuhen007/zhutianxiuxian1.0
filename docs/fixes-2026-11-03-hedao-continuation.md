# 转修后同名道统续接修复

已合道的修士转修后，旧修炼体系可能仍绑定原路线，导致当前路线提示先合道，而再次合道又提示已有体系。本次补齐原道统向当前主修的显式续接。

- 使用 `#合道 原道统名` 续接同一体系；同路线再次合道仍按原规则拒绝，换名不会额外创建体系。
- 当前主修须实际达到秘境仙王巨头、仙古帝光仙王或花粉仙王巨头，并圆满该路线原有道则。旧路线较高境界和旧帝劫结果均不抵扣。
- 原体系名、开创者、创建时间与旧资料保留；完整旧体系、目标路线原道果、续接时间及道则凭据归档。当前路线、来源与阶段更新后，仍沿当前路线完成 `#破王成帝劫`。
- 已有己道推演、六境、神胎、成帝或道外进度，或自身之道明确属于其他路线时，先提示核对，保持原记录。
- 合道入口统一频道账号映射，进行中历练和渡劫先等待结算。保存失败给出未确认提示；续接不重复授予初次合道成就，也不额外扣资源或发放奖励。

破王成帝入口按当前主修核验，旧体系未续接时直接给出同名合道指令。原悟道、寿元、突破、费用和装备计算规则保留。
