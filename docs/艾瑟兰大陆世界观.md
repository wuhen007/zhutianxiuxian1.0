# 艾瑟兰大陆世界观设定集

日期：2026-10-15。定位：「剑与魔法」独立开局路线的世界观母本。游戏内 `#剑与魔法 世界观` 展示的是浓缩版，本文档是完整设定，后续扩内容（新地区、新势力、新职业）都以此为准。

---

## 一、纪元史

### 1. 初火纪元（不可考）
地脉从世界深处苏醒，像心脏第一次搏动。古龙与巨人沿地脉支流筑巢，元素尚未有名字。此纪元没有文字遗存，只有矮人锻匠口中"火比山年长"的谚语。

### 2. 圣约纪元（约两千年前～417 年前）
古代王庭崛起于地脉主脉之上，建成**地脉炉**——一座能把世界地脉转化为秩序之力的巨构。王庭以此立下**旧约**：

- **勇者**：封印之职。在地脉躁动的周期峰值（后世称"裂月"），以自身誓约为楔，钉住地脉炉的阀口。
- **魔王**：守隙之职。世代镇守世界边缘的裂隙，挡住从缝外渗入的"无"。

两职本是一体两面：一个向内地脉负责，一个向外裂隙负责。王庭、圣堂与魔族各保存了旧约的一部分，谁都没有完整的真相。

### 3. 断冠纪元（417 年前～今）
第 N 代勇者在裂月之夜折断王冠、拒绝献祭，史称"断冠者"。王庭随即改写史书：勇者仍是击败魔王的英雄，魔王仍是万恶之源——**英雄叙事成为地脉炉的遮羞布**。此后四百年，地脉炉无人维护，持续抽取地脉，大陆魔力潮汐逐年紊乱。

**现在：断冠纪元第 417 年。裂月将临。**

## 二、地理

| 地点 | 说明 |
|---|---|
| **白桦镇** | 边境小镇，冒险者公会分站所在地。玩家出生地，驿站、锻炉、小圣堂俱全，是所有冒险的起点与归处。 |
| **风鸣林** | 森裔精灵的林地。木精灵的歌声断在一棵倒生的树前——树根里封着王室铸造的**魔力钉**，林中异变源自四百年前的征收旧约。 |
| **灰钟地窟** | 废弃钟楼下的亡灵每天重复同一次祈祷。古钟曾为王国抽取地脉计时；亡灵守着一位**被抹去姓名的工程师**——他发现了地脉炉的用途，于是圣堂公告宣称此地"从未安葬过人"。 |
| **雾桥驿** | 商路要冲。魔族难民从这里涌入，领主要求封桥；公会却委托护送一个持有**旧时代地图**的孩子——地图标明灾变中心位于王都，而非宣传中的魔王领。 |
| **断冠遗迹** | 断冠者折冠之地。王冠残片悬在无声大厅，凡念出咒文者都会被封印当作入侵者；唯有无吟唱者能静默解析。历代勇者的誓约记录于此，**每一份都在为地脉炉支付代价**。 |
| **黑曜边城** | 世界边缘。魔王的守军在这里世代抵挡裂隙；城外人类军团的旗帜上，刻着与勇者遗迹武装相同的纹章——两军本是同一份誓约的两翼。 |
| **裂月王庭** | 古代王庭遗址，地脉炉所在。裂月之夜地脉炉开始吞噬大陆，旧约的三份残章在这里拼出最后的解法。 |

## 三、种族

- **人类**：王国主体，务农、经商、从军、入学。对魔族的恐惧是四百年宣传的产物。
- **森裔精灵**：退守风鸣林等古老林地，记得旧约的另一面。低阶木精灵可被"精灵亲和"者听见；风精灵可与旅人缔结契约。
- **矮人**：锻匠一族，隐居地窟与矿脉，铸造技艺源自初火纪元。古代晶片是他们识别"同源火"的信物。（*扩展钩子：矮人锻匠线·武装进阶*）
- **魔族**：守隙者的后裔。长角与暗纹是世代贴近裂隙的印记，却被王国定性为"魔王血脉"。黑曜边城的守军从未停止抵挡裂隙——哪怕他们保护的世界把他们叫作怪物。

## 五、力量体系

**地脉**是世界的血液循环。所有超凡力量都取自地脉，只是取用方式不同：

- **魔法**：理解元素 → 构筑术式 → 支付魔力。咏唱用于稳定术式；**无吟唱者**跳过咏唱直接构筑，但仍受知识、魔力与熟练度限制。
- **斗气（剑士）**：以呼吸法引导地脉淬炼肉体，正面突破最为稳健。
- **圣术（僧侣）**：以誓愿与圣印引导地脉支流，擅长净化与庇护——圣术的本质是"借调"，所以圣堂最怕有人追问"向谁借"。
- **侦察（游侠）**：追踪、射击、野外生存与遗迹勘探，是最接近"真相"的职业。

**古代晶片**：地脉炉时代的造物残片，矮人锻匠可将其熔入武装。职业武装成型后，所有冒险应对能力获得稳定提升。

## 六、三条终局的设定含义

第六章「裂月王庭」的三选一，本质是对旧约的三种回答：

| 终局 | 选择 | 含义 |
|---|---|---|
| **黎明勇者** | 重铸勇者誓约 | 以自我为新封印。英雄叙事延续，但这一次由你定义"勇者"的含义。 |
| **地脉贤者** | 织补地脉 | 拆解地脉炉，把被垄断了千年的力量还给众生。魔法从此不再是特权。 |
| **守隙魔王** | 继承守隙王冠 | 接过世代污名，成为新的守隙者。拯救世界的方式，是替它背负骂名。 |

三条路没有高下，只有代价不同——这也是六地区见闻全部指向的核心命题：**谁是敌人，要靠证据判断，而不是史书。**

## 七、飞升接续（已落地）

完成六地区主线并写下终局的角色，可发送 `#剑与魔法 飞升 确认` 离开艾瑟兰：

- **门槛**：主线 6/6 + 终局已定 + 职业武装已锻造 + 等级 ≥8（防速成刷号）。
- **落点**：仙界，练气 `level_id=39`「真界境后期」，修为清零重新积累——比复活地球毕业（42 地仙）低一档，体现两条路线的难度差。
- **折算**：随身铜币按 1:100 折为灵石；命宫额外显化传说词条【异界归人】（不占原有命格位）；按终局发放绑定信物一件——黎明勇者→【黎明誓约剑】、地脉贤者→【地脉织针】、守隙魔王→【守隙王冠】（均绑定本人、不可交易、不可支取）；另按风鸣林际遇赠送仙宠——同伴莉娅→【巡礼僧侣莉娅】、精灵契约→【风精灵希露】、都未结缘→【白桦镇信使雀】（三分支都有，不因当时的抉择永久亏待玩家）。异界档案封存只读，`#剑与魔法 回顾` 可随时翻看。
- **设定解释**：职业武装是跨入诸天的信物；三条终局决定的是"你带着哪种答案离开"，不影响落点境界。
- **红线**：飞升一次性、二次确认、折算幂等；信物走「待发标记 + 纳戒回执」两层防重，进程中断也会由后台任务补发，不会重复也不会丢失；未通关角色可随时走 `#再入仙途` 转世出口（断绝此生清空整档）。
