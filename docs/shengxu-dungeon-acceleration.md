# 圣墟副本加速

`#探索圣墟 地点名`、`#沉迷圣墟 地点名*次数`，以及对应法身探索，均使用当前角色的副本加速计算出发耗时。

- 保留呼吸法减时及其原有五分钟基础下限，再叠加行字秘（优先于天璇步法）、有效期内的道法仙术和命格秘境加速。
- 随后应用现有功法熟练度与先天至宝的副本时间倍率，再计算天空权柄的六十秒减时；最终每轮至少一秒。
- 沉迷按加速后的单轮时长安排各轮。`#圣墟副本` 面板展示同一计算结果。

真身正在探索或沉迷圣墟时，可发送：

```text
#消耗仙品秘境结算卡*1
#一键消耗结算卡
```

六种品质结算卡均可使用，面值沿用原配置。圣墟剩余时间不足一张卡的面值时，可扣一张结清；多张请求只扣本次所需张数。一键消耗仍优先使用低品卡。

卡片推进整条探索时间轴，后台同步提前归来和沉迷各轮的结算时间。已结算轮次保留原身份，不重复发放；未结算轮次按原有每批最多十轮的规则补结，全部完成后发送一次汇总。定时任务每二十秒检查一次，长批次可能分多次处理。

已出发的圣墟任务也支持卡片加速；出发后的新加成需下次进入副本时生效。卡片入口继续操作真身行动，法身继承出发时的副本加速。
