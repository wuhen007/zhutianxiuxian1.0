# 路尽级仙帝重证

- 曾经真实达到路尽级仙帝或更高境界，后来跌至准仙帝的玩家，可在群内发送 `#证道` 重登路尽级仙帝，无需重走二十次己道推演或尸骸帝战。
- 人体秘境、仙古今世法、花粉进化路均可：分别由20→21、21→22、21→22，沿当前主修体系恢复，其他体系不提升。
- 重证成功清空【修为】和【血气】，不额外消耗心神、元神、潜力、寿元或纪元积累；空闲、真身和存活要求保留，不提前解除身灭道消、形神俱灭、永祭泡影或行动锁。
- 正式晋升、境界跌落和两个通用存档写入口均记录【曾达路尽级仙帝】；旧档可由己道推演成帝完成记录、成帝时间或已登记的仙帝道果事实识别。半步仙帝、神胎、二十次推演或包含“仙帝”的称号本身均不足以取得资格。
- 现行天意压制等写入规则继续生效；若保存或属性重建异常，回滚境界、修为、血气与装备文件。
- 没有成帝历史的普通修士，`#证道` 仍走原流程，不提前开放仙帝门槛。已处于路尽级仙帝及以上者不会重复重证或被清空修血。
