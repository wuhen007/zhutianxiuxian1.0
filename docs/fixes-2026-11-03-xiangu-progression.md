# 仙古高阶冲关前路指引修复

仙古今世法达到准仙帝后，普通冲关与极境冲关现在按本人实际进度给出已有晋升入口，替换“后续内容还在更新”的占位回复。

- 准仙帝先完成自身之道：未创道提示 `#创造自身之道`；已有自身之道时提示修炼至阶段六、累计三百次；补齐本人修炼体系后进入 `#推演己道`。已有神胎恢复、六境设立与推演记录按原状态指引。
- 路尽仙帝沿原自身之道、祭道推演、道心与厄土击杀条件，通过 `#祭道` 核对下一步；祭道沿原始祖永祭、空间泡影及现实七百二十分钟流程。
- 祭道之上持有本人已认主的大道至宝后，继续用公开版原有 `#证道` 入口核对资粮与状态；唯一道之上提示 `#修仙状态`。

高阶指引在普通冲关的位面文件、位面压制与潜力检查之前返回，查看前路不扣资源、不改存档、不启动试炼。原低境界极境分流、普通突破门槛、费用、成功率和专用晋升流程保持；本次没有新增高阶极境或提前晋升。
